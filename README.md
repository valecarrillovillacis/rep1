# EcoRutas: Aventura Aurora

Un micro-juego de aventura ambiental creado para impresionar con visuales brillantes y un bucle arcade accesible. Explora santuarios nórdicos, recolecta energía bioluminiscente y evita la niebla tóxica para reactivar los faros verdes de cada isla.

## Cómo jugar
1. Abre `index.html` en tu navegador favorito.
2. Usa las teclas **WASD** o las flechas para mover a Aurora.
3. Recolecta todas las fichas turquesa y luego entra al halo del faro verde para avanzar al siguiente nivel.
4. Esquiva la niebla púrpura: si agota toda tu energía, ¡la guardiana deberá reiniciar su travesía!

## Características
- Tres niveles distintos con ritmos crecientes: Isla de los Cantos, Bahía de Cristal y Fjord de Lumen.
- Visuales inspirados en auroras boreales usando gradientes dinámicos de CSS y efectos glow en Canvas.
- Sistema de energía, puntuación por fichas recolectadas y cronómetro en tiempo real.
- Panel narrativo con historia, tecnología empleada, cronograma de producción y mecánicas clave.

## Tecnología
- **HTML5 Canvas** para renderizar entidades, efectos lumínicos y animaciones.
- **JavaScript** para la lógica de juego, detección de colisiones y manejo de niveles.
- **CSS3** para la composición UI neón, diseño responsivo y estilo de tarjetas narrativas.
