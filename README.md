# Thrifty

Prototipo web de un marketplace tipo Poshmark enfocado en moda circular y utilidades premium.

## Características destacadas

- **Perfil vendedor/comprador claro:** stats visibles, verificación y reputación.
- **Publicación rápida:** formulario con sugerencias de precio y etiquetas automáticas.
- **Feed personalizado:** cards estilo TikTok-shopping con likes, guardados y seguimiento.
- **Negociación en chat:** ofertas, contraofertas y promos relámpago activables.
- **Herramientas sociales:** outfit builder, colecciones, actividad y bundles.
- **Gamificación estratégica:** badges, retos y progreso hacia niveles superiores.
- **Checkout y logística:** resumen de pagos seguros, cálculo de envíos y políticas de devoluciones.
- **Dashboard vendedor:** KPIs, top sellers y recomendaciones accionables.
- **Soporte y navegación demo-ready:** menú responsive, chips inteligentes, búsqueda global y módulo de ayuda accionable.

## Cómo usar

1. Abre `index.html` en tu navegador (puedes servirlo con `python -m http.server 8000`).
2. Usa la barra superior: el buscador global sincroniza con la sección de filtros y el botón de menú despliega acciones en móviles.
3. Filtra el inventario con la búsqueda inteligente, los chips por estilo/categoría o el botón **Reiniciar filtros** para volver al estado inicial.
4. Publica un nuevo producto para ver cómo se refresca el feed, las notificaciones, el outfit builder y el dashboard de KPIs.
5. Prueba la negociación en chat, activa una promo relámpago, calcula envíos y arma bundles para validar toda la experiencia transaccional.
6. Visita el módulo de soporte y los accesos rápidos (Ingresar, ayuda, CTA del hero) para comprobar que cada click responde dentro del prototipo.

Todo el contenido corre localmente con HTML, CSS y JavaScript puro, ideal para demos rápidas o handoff de diseño/Producto.
